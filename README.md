# latent-causal
Code for implementing a two-step causal inference approach for survival outcomes under longitudinal latent confounding

### Reference
Liu Y, Fiocco M & Spreafico M. A two-step causal inference approach for survival outcomes with longitudinal latent confounding: an application to treatment modifications in Ewing sarcoma. *[Submitted]*


### Data Availability
We cannot provide the original EE2012 trial data analysed due to confidentiality restrictions. 
We therefore provide a pseudo-data dataset that allows researchers to reproduce the analyses, understand how the code should be run, and inspect how the results are generated, displayed, and interpreted.


## Description
These analyses use the pseudo-data example (`./data/fake_data.csv`) and are intended to illustrate the implementation of the two-step approach.

- Files (to be run in order, with the working directory set to the root of this repository):
  - `01_data_description.R` reproduces Figures 3 and 4 for the pseudo-data example.
  - `02_step1_LMMselection.R` reproduces the selection of the final Latent Markov Models (LMMs) for the pseudo-data analyses, along with Supplementary Table B.1. The final fitted LMM is saved in `./results/LMM_final.RData`.
  - `03_step1_LMMresults.R` reproduces the results of the final fitted LMM `./results/LMM_final.RData`, specifically Figure 5 and Table 1, and the computation of the relative risk profiles `./results/RR_profiles.RData`, along with Figure 6.
  - `04_step2_IPWselection.R` reproduces the analysis of the different IPTW and IPDW specifications for the pseudo-data analyses, along with Supplementary Figures C.1 and C.2. The weighted dataset under the final specifications is saved in `./results/IPW_final.RData`.
  - `05_step2_CoxMSM.R` fits the final marginal structural Cox model (Cox-MSM) on the pseudo-data, computes the RMST differences between treatment strategies with 95% bootstrap confidence intervals, and reproduces Figure 7.

- Sub-folder **./data/** contains the pseudo-data dataset and its variable legend:
	- `data_legend.txt`: Variables legend of dataset 'fake_data.csv'.
	- `fake_data.csv`: Datasets related to 500 fake subjects.

- Sub-folder **./functions/** contains auxiliary functions used by the main scripts:
  - `lmm_functions.R`: functions for Step 1 (data preparation, fitting and selection of the LMMs, relative risk profiles);
  - `ipw_functions.R`: functions for Step 2 (IPTW and IPDW specifications and stabilized weights);
  - `msm_functions.R`: functions for Step 2 (Cox-MSM, RMST under treatment strategies, bootstrap).

- Sub-folder **./results/** contains the fitted model objects, the tables and figures generated by the application scripts:
  - `LMM_final.RData`, `RR_profiles.RData`, `IPW_final.RData`, `CoxMSM_final.RData` and `CoxMSM_RMST.RData` contain the fitted models and intermediate results;
  - **./results/figures/** contains the figures saved as `.pdf` files, with filenames corresponding to the manuscript figures;
  - **./results/tables/** contains the tables saved as `.csv` files, with filenames corresponding to the manuscript tables.
